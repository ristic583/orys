Four skills, one brief

Each page was built by following a single skill, using the same data (the Links project plus four others) and the same three screens: the projects overview, a project's plan as a step diagram with actions, and the new-project wizard. Every page is clickable: open a task, switch wizard modes, step through questions.

My pick for AI PM: A's direction, built with D's engine.

frontend-design (A) gives the clearest "project in focus" overview and the most distinctive look. react-flow (D) is the only skill that actually teaches the diagram layer (real pan and zoom, grouped phases, auto-layout, actions inside nodes), so it's what the plan editor in M10 should be built on. Use ui-ux-pro-max (B) as an accessibility and states checklist rather than as the style source. dashboard-design (C) adds the least: it's a short style note that produces a generic admin template.
